# GitHub Pages でホームページを公開する手順

このホームページを GitHub（ギットハブ）という無料のサービスに置いて、
インターネット上の URL（アドレス）で見られるようにする手順です。
費用はかかりません。パソコンに新しいソフトを入れる必要もありません。

---

## はじめに：3つだけ知っておいてください

### 1. いまは「検索避け」を入れた状態になっています

GitHub Pages には「この人だけに見せる」という機能がありません
（閲覧制限をかけられるのは法人向けの最上位プランのみで、
無料プランでも有料の個人プランでも、公開したページは誰でも見られます）。

そのかわり、いまは **検索避けの設定** を入れてあります。
`index.html` と `eitaikuyo.html` の先頭に次の1行が入っています。

```html
<meta name="robots" content="noindex">
```

この1行があるあいだは、**Google などの検索結果にこのページは出てきません。**
URL を知っている人だけがたどり着ける状態です。まずはこの状態で公開し、
お父さまに URL を送って内容を確認してもらってください。

内容が固まって、本格的に検索から見つけてもらいたくなったら、
**両方のファイルからこの1行を消すだけ**で切り替わります
（消し方は「あとから内容を直したいとき」を参照してください）。

なお、パスワードがかかるわけではありませんので、
URL が他の人に転送されればその人も見られます。

### 2. まだ埋まっていないところ

写真の枠が2か所、「写真を準備中です」のままです。
本格公開の前に、写真を用意するか枠を消すかを決めてください。

| 箇所 | 現在の内容 |
|---|---|
| 住職の写真（トップページ） | 「写真を準備中です」の枠 |
| 永代供養墓の写真 | 「写真を準備中です」の枠 |

電話番号（059-378-0953）と住所は本物が入っています。
公開されると誰でも見られますが、寺の連絡先ですので問題ありません。
お問い合わせはお電話のみの受付とし、メール欄は設けていません。

### 3. 打ち合わせ用の資料も一緒に公開されます

`docs` フォルダの中に、このホームページを作るときの設計メモが入っています。
公開したくない場合は、`docs` フォルダごと消してから公開してください
（ホームページの表示には一切影響しません）。

## 手順

### ステップ1：GitHub のアカウントを作る（5分）

1. https://github.com/signup を開く
2. メールアドレス、パスワード、ユーザー名を決めて入力する
   - **ユーザー名がそのまま URL に入ります。** `saikoji` のように、
     寺の名前にちなんだ短い英数字がおすすめです
3. 届いたメールに書かれた数字を入力して、メールアドレスを確認する
4. 料金プランを聞かれたら「Free（無料）」を選ぶ

### ステップ2：置き場所（リポジトリ）を作る（3分）

1. ログインした状態で https://github.com/new を開く
2. 次のように入力する
   - **Repository name**：`saikoji`（半角英数字。これも URL に入ります）
   - **Public / Private**：**Public** を選ぶ
     - Private（非公開）だと、無料プランでは Pages が使えません
     - ここでいう Public はファイルの置き場所の話です。
       ホームページ自体が検索に出るかどうかは、上で説明した「検索避け」で決まります
   - **Add a README file / .gitignore / license のチェックは入れないでください**
     （空の状態で作るのが大事です。何か入っているとステップ3で失敗します）
   - そのほかの項目は触らなくて構いません
3. 緑色の **Create repository** ボタンを押す

### ステップ3：パソコンからファイルを送る（5分）

このフォルダはすでに Git で管理されていますので、
GitHub とつなぐ設定を一度だけすれば送れます。

エクスプローラーで `西光寺ホームページ` フォルダを開き、
何もないところで右クリック →「Git Bash Here」を選びます。
黒い画面が開いたら、次の2行を順番に貼り付けて Enter を押してください。

```bash
git remote add origin https://github.com/ユーザー名/saikoji.git
git push -u origin main
```

- 1行目の `ユーザー名` は、ご自身の GitHub のユーザー名に置き換えてください
  （ステップ2の画面に表示されている URL をそのままコピーするのが確実です）
- 2行目を実行すると、**ブラウザが開いて GitHub のログイン画面**が出ます。
  「Authorize」「Continue」などのボタンを押してログインしてください。
  ログインは初回だけで、2回目以降は聞かれません

`Branch 'main' set up to track 'origin/main'` のような表示が出れば成功です。
GitHub の画面を再読み込みすると、ファイルの一覧に `index.html` などが並びます。

> **うまくいかないとき**：GitHub のリポジトリ画面にある
> **uploading an existing file** のリンクから、フォルダの中身
> （`index.html`, `eitaikuyo.html`, `favicon.svg`, `css`, `js`, `images`, `docs`）を
> ドラッグ＆ドロップしても同じことができます。

### ステップ4：公開の設定をする（2分）

1. リポジトリの画面の上のほうにある **Settings**（歯車のマーク）を押す
2. 左側のメニューから **Pages** を押す
3. **Branch** のところが `None` になっているので、`main` に変更する
   （`main` がなく `master` だけある場合は `master` を選んでください）
4. その右のフォルダは `/ (root)` のままにする
5. **Save** を押す

### ステップ5：URL を確認する（1〜5分待つ）

Save を押してから1〜5分ほどで公開されます。
同じ **Pages** の画面を再読み込みすると、上のほうに URL が表示されます。

**西光寺のホームページの URL は次のとおりです。**

```
https://saikojimakitayama.github.io/saikoji/
```

この URL をお父さまに LINE やメールで送れば、スマホでもパソコンでも見られます。

## 公開したあとにやること

### 1. og:url の書き換え（対応済み）

`index.html` と `eitaikuyo.html` の `og:url` と `og:image` は、
上の URL に書き換え済みです。
LINE などで URL を送ると、寺の写真とページの説明が表示されます。

### 2. 内容を確認してもらう

URL をお父さまに送って、内容を見てもらってください。
直したいところが出てきたら教えてください。

### 3. 本格公開に切り替える

内容が固まったら、次の3つをやると検索から見つけてもらえるようになります。

1. `index.html` と `eitaikuyo.html` から
   `<meta name="robots" content="noindex">` の行を削除する
2. 写真の枠（2か所）を、写真に差し替えるか削除する
3. `docs/google-business-profile-guide.md` の手順で Google ビジネスプロフィールに登録し、
   「ウェブサイト」の欄にこの URL を入れる

検索で見つけてもらうには、ホームページ単体より
Google ビジネスプロフィールのほうが効果があります。

## あとから内容を直したいとき

### 方法A：パソコンで直して送る（おすすめ）

ステップ3を済ませていれば、以降はこの3行だけです。

```bash
git add -A
git commit -m "内容を修正"
git push
```

1分ほどでホームページに反映されます。
パソコン側のファイルが常に最新になるので、こちらをおすすめします。

### 方法B：GitHub の画面上で直す

パソコンが手元にないときはこちらでも直せます。

1. リポジトリの画面で、直したいファイル（例：`index.html`）を押す
2. 右上の鉛筆マークを押す
3. 文字を直して、下の **Commit changes** を押す

ただしこの方法で直すと、**パソコン側のファイルが古いまま**になります。
次にパソコンで作業する前に `git pull` を実行して、変更を取り込んでください。

## よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| URL を開くと「404」と出る | 公開直後はまだ準備中です。5分ほど待って再読み込みしてください |
| 文字だけ表示されて、色や配置が崩れている | `css` フォルダがアップロードされていません。ステップ3をやり直してください |
| 写真が表示されない | `images` フォルダがアップロードされていません。同上 |
| Pages の設定画面に `main` が出てこない | ファイルがまだアップロードされていません。ステップ3を先に済ませてください |
| `remote origin already exists` と出る | すでに設定済みです。`git remote set-url origin https://github.com/ユーザー名/saikoji.git` で入れ直してください |
| `failed to push some refs` と出る | リポジトリを作るときに README などを入れてしまった可能性があります。`git pull --rebase origin main` を実行してから、もう一度 `git push -u origin main` してください |
| ログイン画面が開かない／閉じてしまった | もう一度 `git push -u origin main` を実行すると、また開きます |
