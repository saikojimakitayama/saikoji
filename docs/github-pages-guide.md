# GitHub Pages でホームページを公開する手順

このホームページを GitHub（ギットハブ）という無料のサービスに置いて、
インターネット上の URL（アドレス）で見られるようにする手順です。
費用はかかりません。パソコンに新しいソフトを入れる必要もありません。

---

## はじめに：3つだけ知っておいてください

### 1. 公開すると、世界中の誰でも見られます

GitHub Pages の無料プランには「この人だけに見せる」という機能がありません。
URL を知っている人だけでなく、Google などの検索結果にも表示されるようになります。

西光寺のホームページは、もともと永代供養墓を知ってもらうことが目的ですので、
**公開してよい**という判断で問題ありません。
ただし「まずは父だけに見せて、内容を確認してから世に出したい」という場合は、
公開前に下の「まだ直っていないところ」を先に直してください。

### 2. まだ直っていないところ

公開すると誰でも見られるため、公開前に次の2つを決めてください。

| 箇所 | 現在の内容 | どうするか |
|---|---|---|
| メールアドレス | `info@example.com`（仮のもの） | 本物に差し替える、または「電話のみ」にしてメール欄を消す |
| 住職の写真 | 「写真を準備中です」の枠 | 写真を用意する、または枠を消す |
| 永代供養墓の写真 | 「写真を準備中です」の枠 | 写真を用意する、または枠を消す |

電話番号（059-378-0953）と住所は本物が入っています。
これらは公開されると誰でも見られますが、寺の連絡先ですので問題ありません。

### 3. 打ち合わせ用の資料も一緒に公開されます

`docs` フォルダの中に、このホームページを作るときの設計メモが入っています。
公開したくない場合は、`docs` フォルダごと消してから公開してください
（ホームページの表示には一切影響しません）。

## 手順

### ステップ1：GitHub のアカウントを作る（5分）

1. https://github.com/signup を開く
2. メールアドレス、パスワード、ユーザー名を決めて入力する
   - **ユーザー名がそのまま URL に入ります。** `saikoji` のように、
     寺の名前にちなんだ短い英数字がおすすめです
3. 届いたメールに書かれた数字を入力して、メールアドレスを確認する
4. 料金プランを聞かれたら「Free（無料）」を選ぶ

### ステップ2：置き場所（リポジトリ）を作る（3分）

1. ログインした状態で https://github.com/new を開く
2. 次のように入力する
   - **Repository name**：`saikoji`（半角英数字。これも URL に入ります）
   - **Public / Private**：**Public** を選ぶ
     - Private（非公開）だと、無料プランでは Pages が使えません
   - そのほかの項目は触らなくて構いません
3. 緑色の **Create repository** ボタンを押す

### ステップ3：ファイルをアップロードする（5分）

作られた画面に **uploading an existing file** という青い文字のリンクがあります。
それを押すとアップロード画面になります。

1. エクスプローラーで `西光寺ホームページ` フォルダを開く
2. **フォルダの中身**を全部選んで（フォルダごとではなく、中身です）、
   アップロード画面にドラッグ＆ドロップする
   - `index.html`, `eitaikuyo.html`, `favicon.svg`, `css`, `js`, `images`, `docs`
   - `.git` という隠しフォルダは、表示されていなければそのままで構いません
3. 画面下の緑のボタン **Commit changes** を押す

しばらく待って、ファイルの一覧に `index.html` などが並べば成功です。

### ステップ4：公開の設定をする（2分）

1. リポジトリの画面の上のほうにある **Settings**（歯車のマーク）を押す
2. 左側のメニューから **Pages** を押す
3. **Branch** のところが `None` になっているので、`main` に変更する
   （`main` がなく `master` だけある場合は `master` を選んでください）
4. その右のフォルダは `/ (root)` のままにする
5. **Save** を押す

### ステップ5：URL を確認する（1〜5分待つ）

Save を押してから1〜5分ほどで公開されます。
同じ **Pages** の画面を再読み込みすると、上のほうに URL が表示されます。

```
https://（ユーザー名）.github.io/saikoji/
```

たとえばユーザー名が `saikoji-suzuka` なら
`https://saikoji-suzuka.github.io/saikoji/` になります。

この URL をお父さまに LINE やメールで送れば、スマホでもパソコンでも見られます。

## 公開したあとにやること

### 1. og:url の書き換え（任意）

URL が決まったら、`index.html` と `eitaikuyo.html` の先頭にある
`https://example.com` という部分を、実際の URL に書き換えてください。
LINE などで URL を送ったときに、寺の写真と説明が表示されるようになります。

### 2. Google ビジネスプロフィールへの登録

`docs/google-business-profile-guide.md` の手順に沿って登録し、
「ウェブサイト」の欄にこの URL を入れてください。
検索で見つけてもらうには、ホームページ単体よりこちらのほうが効果があります。

---

## あとから内容を直したいとき

GitHub の画面上で直せます。

1. リポジトリの画面で、直したいファイル（例：`index.html`）を押す
2. 右上の鉛筆マークを押す
3. 文字を直して、下の **Commit changes** を押す

1分ほどでホームページに反映されます。

## よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| URL を開くと「404」と出る | 公開直後はまだ準備中です。5分ほど待って再読み込みしてください |
| 文字だけ表示されて、色や配置が崩れている | `css` フォルダがアップロードされていません。ステップ3をやり直してください |
| 写真が表示されない | `images` フォルダがアップロードされていません。同上 |
| Pages の設定画面に `main` が出てこない | ファイルがまだアップロードされていません。ステップ3を先に済ませてください |
