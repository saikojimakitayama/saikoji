# 西光寺ホームページ コンテンツ拡充 設計スペック

## 背景・目的

西光寺のホームページは公開済み（https://saikojimakitayama.github.io/saikoji/、検索避け適用中）で、永代供養墓の専用ページ・料金表・FAQ・申込みの流れまで揃っている。しかし問い合わせにつながる要素が不足している。

人気寺院サイトおよび永代供養墓の集客に関する調査から、次の指摘を得た。

- **料金しか載っていない寺は価格だけで比較される。供養への想い・住職の人柄・年間法要・地域とのつながりを発信している寺が「安心して任せられる」として選ばれる**
- 写真は本堂・山門・墓所・境内・法要の様子・駐車場・住職の顔写真など多数が推奨される
- 検討者は複数寺院を見比べる。情報量の少ないサイトは比較対象から外れる
- 「永代供養墓とは」「墓じまいの流れ」といった教育系ページが検索の入口として有効
- 電話以外の問い合わせ手段（フォーム）があると問い合わせが増える

現状の西光寺サイトは、永代供養墓の**商品情報**では調査対象の寺院サイトを上回る一方、**寺そのものの魅力**がほぼ伝わらない。本スペックはこの不足を埋め、問い合わせ数を増やすことを目的とする。

デザインの全面刷新は行わない。現在の読みやすさ（基準18pxの文字、単純な構造、和の配色）は高齢の読み手に合わせて意図的に作った資産であり、これを維持したままコンテンツを厚くする。

## 確定事項（依頼者確認済み）

- 見直しの優先度: **問い合わせを増やすこと**（見た目の刷新ではない）
- 用意できる素材: **境内・本堂・墓所の写真**、**住職の顔写真**
- 住職の言葉（供養への想い）: 後日ヒアリング予定。**現時点では未取得**
- 問い合わせ手段: 電話に加えて**問い合わせフォームを追加**（Googleフォームを使用）
- お知らせ欄: **設ける**。更新は依頼者から内容を受け取り、こちらで反映する
- 改葬許可証: 先の「不要」は**西光寺が提出を求めない**という意味。**墓じまい解説ページで取得手続きに触れてよい**

## 重要な制約

### 教義に関わる表現（既存スペックから継承）

真宗高田派において「回向」は阿弥陀仏から衆生へ向かうものであり、生者が故人へ功徳を振り向ける追善供養の意味ではない。

- 「ご回向します」「追善供養」など追善の意味を含む表現を使わない
- 教義の説明は最小限にとどめ、実務的な事実を書く
- 法要は自動的に勤めるものではなく、希望があればお勤めするものとして書く

### 住職の言葉を創作しない

「供養への想い」「メッセージ」は住職本人の言葉であるべきものである。ヒアリング前に、それらしい文章をこちらで作成して仮置きしてはならない。当該箇所は事実ベースの記述にとどめ、差し替え位置を日本語コメントで明示する。

### 事実でないことを書かない

集客目的であっても、確認が取れていない事実を書かない。特に次は書いてはならない。

- 近隣市（四日市市・亀山市など）からの来訪実績（未確認）
- 利用者の声・体験談（存在しない）
- 永代供養墓の設置年、これまでの受け入れ実績（未確認）
- お布施の金額の目安（掲載しない方針が確定済み）

### 改葬許可証の書き方

墓地埋葬法上、ご遺骨を既存の墓地から移すには市区町村が発行する改葬許可証が必要であり、これは**現在の墓地から遺骨を出すために必要**なものである。したがって西光寺が提出を求めないかどうかにかかわらず、墓じまいをする本人には必要になる。

- `hakajimai.html` では、市区町村での取得手続きを**手順の一部として説明する**
- 「西光寺では提出を求めておりません」とは**書かない**。読み手が「改葬許可証そのものが不要」と誤解し、不利益を被る恐れがあるため
- `eitaikuyo.html` には改葬許可証の記述を戻さない。手続きの詳細は `hakajimai.html` へのリンクで案内する

### 高齢者への配慮を壊さない

- 基準文字サイズ 18px（`html { font-size: 112.5% }`）を下げない
- 新規に追加する文字も 0.85rem を下回らない
- スマホ幅 320px で横スクロールを発生させない

### 公開の制御

- **依頼者の承認があるまで GitHub へ push しない**。ローカルでのコミットは可
- `<meta name="robots" content="noindex">` は当面維持する

## 成果物

### 1. トップページ（`index.html`）の改修

**セクション順の変更**

```
現在： hero → about → priest → events → memorial → access → contact
変更： hero → news → about → priest → events → memorial → access → contact
```

**お知らせ欄（`#news`、新規）**

- 最新3件を日付＋見出しの一覧で表示する
- 各項目は日付・タイトル・本文1〜2文の構成
- 記事個別ページは作らない（件数が少なく、管理コストに見合わないため）
- 初期内容は依頼者から受け取る。受け取るまでは年間行事から確実に言える事実（例：11月に報恩講を勤めた等）を置かず、**空欄のままにせずセクションごと未実装にする**
- 更新方法を `docs/news-update-guide.md` に記載する

**住職紹介（`#priest`）の充実**

- 顔写真を配置（現在はプレースホルダー）
- 氏名・継承年（第十六世 瀬古和順、平成二十九年継承）を明記。これは由緒・沿革に既にある確定情報である
- 供養への想いを書く領域を設け、**住職の言葉が届くまでは事実のみを記載**し、差し替え位置をコメントで示す

**寺の紹介（`#about`）**

- 本堂・境内の写真を配置する
- 本文に「三重県鈴鹿市」を含める（既に含まれている）

**お問い合わせ（`#contact`）**

- 電話番号の下に問い合わせフォームを追加する
- 電話の受付時間について記載しない（未確認のため）

### 2. 永代供養墓ページ（`eitaikuyo.html`）の強化

- **写真**: 「永代供養墓について」セクションのプレースホルダーを実物写真に差し替える
- **地域名**: ページ冒頭のリード文に「三重県鈴鹿市」を自然に含める。現在は `<title>` と `meta description` にしかなく、本文にない
- **中間CTA**: 費用表の直後に問い合わせへの導線（`#contact` へのボタン）を置く。現状は最下部まで到達しないと連絡先に届かない
- **FAQ 2件追加**
  - 生前にお申し込みした場合、費用はいつお支払いしますか
  - ご遺骨は誰が持って行けばよいですか
  - いずれも回答内容は住職の確認が必要なため、**確認が取れるまで実装しない**
- **墓じまいページへの導線**: 「こんな方へ」の「墓じまいを考えている」付近と、お申込みの流れの注意ボックスから `hakajimai.html` へリンクする

### 3. 墓じまいの流れページ（`hakajimai.html`、新規）

検索からの入口として作る。「墓じまい 鈴鹿市」「墓じまい 流れ 費用」で調べる層を受け止め、永代供養墓につなげる。

**構成**

1. ページ見出し —「墓じまいの流れ」
2. リード文 — 三重県鈴鹿市の西光寺が、墓じまいのご相談を承っている旨
3. **墓じまいとは** — 現在のお墓を撤去し、ご遺骨を別の場所に移すこと
4. **手続きの流れ**（法的手続きを含む）
   1. ご親族の同意を得る
   2. 移し先（受け入れ先）を決める
   3. 現在の墓地の管理者に連絡する
   4. 現在の墓地がある市区町村で**改葬許可証**を取得する
   5. 閉眼法要とお墓の撤去
   6. 新しい移し先へご納骨
5. **費用について** — 撤去費用・書類手数料・受け入れ先の費用に分かれる旨。**具体的な金額の相場は書かない**（西光寺が把握していないため）。西光寺の永代供養墓の費用のみ、確定情報として案内する
6. **西光寺の永代供養墓へ移す場合** — 費用（檀家以外15万円〜）と、合祀のため取り出せない旨、`eitaikuyo.html` への導線
7. **よくあるご質問** — 親族の同意は必須か／今のお墓が遠方でも相談できるか／宗派が違っても受け入れてもらえるか
8. **お問い合わせ** — 電話＋フォーム

**注意**: 手続きの記述は一般的な流れであり、市区町村により異なる場合がある旨を明記する。

### 4. 問い合わせフォーム

Googleフォームを作成し、`<iframe>` で各ページの問い合わせセクションに埋め込む。

**フォーム項目**

| 項目 | 種類 | 必須 |
|---|---|---|
| お名前 | 記述式（1行） | 必須 |
| ふりがな | 記述式（1行） | 任意 |
| 電話番号 | 記述式（1行） | 任意 |
| メールアドレス | 記述式（1行） | 任意 |
| ご相談内容 | ラジオボタン（永代供養墓について／墓じまいについて／法要について／その他） | 必須 |
| ご質問・ご要望 | 記述式（段落） | 任意 |

電話番号とメールアドレスの両方を任意とするが、フォームの説明文で「ご連絡先をどちらかご記入ください」と補足する。

**実装上の制約**: Googleフォームの作成にはGoogleアカウントが必要であり、こちらでは作成できない。作成手順書 `docs/google-form-guide.md` を用意し、依頼者に作成してもらう。**フォームURLを受け取るまで埋め込みは実装しない。**

埋め込みが未実装の間も、電話番号は従来どおり表示する。

- ヒーロー以外は `loading="lazy"` を付与する
- `alt` 属性に内容を日本語で記述する

- `docs/google-form-guide.md` — Googleフォームの作成手順とURLの取得方法

## 技術構成

既存サイトの構成を踏襲する。

- ビルド不要の静的サイト（HTML / CSS / Vanilla JavaScript）
- 新規ページ `hakajimai.html` はリポジトリ直下に置き、既存の `css/style.css` と `js/script.js` を共用する
- ページ固有のスタイルは `css/style.css` の末尾に追記する
- 既存の共通クラス（`.section`, `.section-inner`, `.section-alt`, `.section-title`, `.about-text`, `.about-note`, `.info-list`, `.info-row`, `.faq-list`, `.flow-list`, `.notice-box`, `.cta-link`）を再利用し、再定義しない
- ヘッダー・フッター・ナビゲーションの構造は既存ページと揃える

**ナビゲーションの扱い**

「墓じまい」を加えるとナビが8項目になる。並び順は次のとおりとし、全ページで統一する。

```
トップ／寺の紹介／住職紹介／年間行事／永代供養墓／墓じまい／アクセス／お問い合わせ
```

「墓じまい」を「永代供養墓」の直後に置くのは、この2つが関連しており、墓じまいを検討する人が永代供養墓に流れる導線に沿うためである。

現在は980px以下でハンバーガーメニューに切り替わるが、8項目では980px前後で横並びが窮屈になる。**切り替え閾値を1100pxに引き上げる**ことで対応する。ドロップダウンメニューは導入しない（実装が複雑になり、タッチ操作でも扱いにくいため）。

**OGP**

`hakajimai.html` にも既存2ページと同じ形式で OGP メタタグを設定する。`og:url` は `https://saikojimakitayama.github.io/saikoji/hakajimai.html`、`og:image` は既存のヒーロー画像を用いる。`<meta name="robots" content="noindex">` も同様に入れる。

## 実装の順序

素材の到着を待たずに進められるものから着手する。

**第1段階（いま着手できる。素材不要）**

1. `hakajimai.html` の新規作成
2. ナビゲーションへの「墓じまい」追加と、切り替え閾値の1100pxへの変更（全ページ）
3. `eitaikuyo.html` の地域名追加・中間CTA・墓じまいページへの導線
4. `index.html` の住職紹介に氏名と継承年を追記（既に確定している事実のみ）
5. `docs/google-form-guide.md` と `docs/news-update-guide.md` の作成

**第2段階（素材が届いてから）**

6. 写真の配置（本堂・境内・墓所・住職の顔写真）
7. 問い合わせフォームの埋め込み（GoogleフォームURL取得後）
8. お知らせ欄の新設とセクション順の変更（初期内容の受領後）
9. 住職の言葉の反映
10. 追加FAQ 2件（住職の確認後）

第1段階だけでも、墓じまいという新しい検索の入口ができ、永代供養墓ページの導線が改善される。第2段階は素材が届き次第、個別に着手する。

## スコープ外

- デザインの全面刷新（配色・フォント・レイアウトの根本的な変更）
- スクロール連動アニメーション、パララックス等の演出
- ブログの定期運用（お知らせは手動更新とする）
- 樹木葬・納骨堂など、存在しない商品の追加
- LINE公式アカウントの開設
- 利用者の声・体験談の掲載（実体がないため）
- 独自ドメインの取得
- 検索避け（noindex）の解除（別途判断する）

## 検証方法

- ブラウザで全3ページを開き、320px / 390px / 768px / 1280px でレイアウト崩れがないことを確認する
- 全ページ間の相互リンクが正しく解決することを確認する（トップ ⇄ 永代供養墓 ⇄ 墓じまい）
- トップページ内の全アンカーリンクが引き続き動作することを確認する
- 「回向」「追善」が全ページに出現しないことを確認する
- 未確認の事実（来訪実績・利用者の声・相場金額）が記載されていないことを確認する
- 新規に追加した文字が 0.85rem を下回っていないことを確認する
- 掲載した費用が確定情報と一致していることを確認する（檀家以外 15万円 / +3万円、檀家 10万円 / +2万円、基本料金に1体含む）
- `hakajimai.html` に改葬許可証の取得手続きが記載され、かつ「西光寺では不要」という趣旨の記述がないことを確認する
