# 永代供養墓ページ 設計スペック

## 背景・目的

西光寺には既に永代供養墓があるが、現在のホームページには一切記載がなく、さらにサイト自体が非公開のため、外部からは存在が認識されていない。

寺院の収益基盤は既存の柱（檀家の護持費、葬儀・法事のお布施、境内墓地の管理料）がいずれも縮小傾向にあり、新しい柱が必要である。永代供養墓は既に用意されている「商品」であり、承継者のいない層・墓じまいを検討する層という拡大市場に向けて、檀家以外にも開かれている。

葬儀依頼は葬儀社経由が主流でありホームページの効果は限定的だが、**永代供養墓は本人が直接インターネットで寺を探すため、ホームページが直接効く領域である。** 本スペックは、この既存商品を発見可能にすることを目的とする。

## 確定情報（住職への確認済み）

- **名称**: 永代供養墓
- **費用**（基本料金にご遺骨1体を含む）
  - 檀家以外の方: 基本料金 15万円 / 1体追加ごとに +3万円
  - 檀家の方: 基本料金 10万円 / 1体追加ごとに +2万円
  - 公開してよい
- **年間管理費**: なし
- **檀家になる必要**: なし（ただし檀家になると費用が安くなる）
- **埋葬方式**: ずっと合祀（個別安置期間は設けない）
- **宗派**: 不問
- **生前申込**: 可能
- **墓じまいからの改葬**: 受け入れ可能
- **区画の残数**: 合祀のため「残数」の概念がない＝常時受け入れ可能
- **永代経法要**: 自動的に勤めるものではない。合祀された方でも、**希望されればお勤めする**
- **墓地の場所**: 永代供養墓は境内ではなく、**境内とは別の場所にある墓地**に設置されている
- **お参り**: **いつでもお参りできる**（時間の制限・事前連絡は不要）
- **改葬許可証**: 不要（ページに記載しない）
- **写真**: 未提供（後日提供予定）

## 重要な制約：真宗の教義に関わる表現

浄土真宗（真宗高田派）において「回向」は阿弥陀仏から衆生へ向かうものであり、生者が故人へ功徳を振り向ける追善供養の意味ではない。

したがって本ページでは以下を守る。

- 「ご回向します」「追善供養」など、追善の意味を含む表現を使わない
- 教義の説明は最小限にとどめ、**実務的な事実**（合祀して埋葬する、希望があれば法要を勤める等）を書く
- 「永代供養墓」は寺が使用している正式名称であるため、名称としてはそのまま用いる
- 教義に関わる表現は住職の確認を前提とし、該当箇所に日本語の編集用コメントを入れる

## 成果物

### 1. 永代供養墓 専用ページ（新規 `eitaikuyo.html`）

検索から直接流入させるため、トップページ内のセクションではなく独立したページとする。

**ページ構成**

1. **ページ見出し** — 「永代供養墓のご案内」
2. **3つの安心**（最上部に大きく配置）
   - 年間管理費なし
   - 檀家にならなくてもお申し込みいただけます
   - 宗派は問いません
3. **こんな方へ**
   - お墓を継ぐ方がいない
   - 墓じまいを考えている
   - 子や孫に負担をかけたくない
   - 元気なうちに決めておきたい
4. **費用**（表形式）

   | | 檀家以外の方 | 檀家の方 |
   |---|---|---|
   | 基本料金（ご遺骨1体を含む） | 15万円 | 10万円 |
   | 1体追加ごと | +3万円 | +2万円 |
   | 年間管理費 | なし | なし |

   ご遺骨の数ごとの目安も併記する（檀家以外: 1体15万円 / 2体18万円 / 3体21万円、檀家: 1体10万円 / 2体12万円 / 3体14万円）。

5. **永代供養墓について**
   - 他の方のご遺骨とともに合祀する形式であること
   - **合祀のため、後からご遺骨を取り出すことはできない旨を明記する**（住職の承諾済み。後日のトラブル防止と信頼性の観点から必須）
   - 合祀のため区画の空き状況に左右されず、いつでもお受けできること
6. **法要について**
   - 永代経法要をご希望の方にはお勤めする旨
   - 自動的に勤めるものではないことが伝わる書き方にする
7. **お申込みの流れ**
   - ご相談・お問い合わせ → ご見学・ご説明 → お申込み → ご納骨
   - 墓じまいからの改葬も受け入れられる旨を補足する（改葬許可証には触れない）
8. **よくあるご質問**
   - 檀家にならないといけませんか
   - 宗派は問われますか
   - 年間管理費はかかりますか
   - 生前に申し込めますか
   - 今あるお墓を墓じまいして移せますか
   - 後からご遺骨を取り出せますか
   - お参りはいつでもできますか（いつでもお参りいただける旨を回答する）
   - 法要をお願いできますか
9. **お問い合わせ** — 電話・メール（現在はプレースホルダー）
10. **写真** — 未提供のため、差し替え可能なプレースホルダーを設置する

### 2. トップページ（`index.html`）の更新

- `#memorial` セクションの「詳細につきましては現在準備中です」を削除し、永代供養墓の要点（3つの安心＋費用の起点となる金額）と専用ページへの導線に差し替える
- ヘッダーナビゲーションに永代供養墓ページへのリンクを追加する

### 3. 公開に向けた調整

外部公開を前提とするため、以下を整備する。

- 各ページの `<title>` と `meta description` に地名・宗派・「永代供養墓」を含め、検索で発見されやすくする
- OGP メタタグ（`og:title` / `og:description` / `og:image` / `og:type` / `og:url`）を追加し、SNS やメッセージアプリで共有された際に適切に表示されるようにする
- ファビコンを追加し、ホスティング時の 404 を解消する

### 4. Googleビジネスプロフィール登録手順書（新規ドキュメント）

ホームページより先に効果が出るため、住職または依頼者がそのまま作業できる手順書を `docs/google-business-profile-guide.md` として作成する。登録手順、オーナー確認、登録後に設定すべき項目（写真、説明文、サービスとしての永代供養墓の登録）を含む。

## 技術構成

既存サイトの構成を踏襲する。

- ビルド不要の静的サイト（HTML / CSS / Vanilla JavaScript）
- 新規ページ `eitaikuyo.html` はリポジトリ直下に置き、既存の `css/style.css` と `js/script.js` を共用する
- 永代供養墓ページ固有のスタイルは `css/style.css` の末尾に追記する（既存タスクで確立した追記方式を踏襲）
- 既存の共通クラス（`.section`, `.section-inner`, `.section-alt`, `.section-title`, `.about-text`, `.about-note`, `.info-list`, `.info-row`）を再利用し、再定義しない
- ヘッダー・フッター・ナビゲーションの構造は `index.html` と揃える。トップページ内アンカーへのリンクは `index.html#about` の形式で記述する
- レスポンシブ対応必須（スマホ幅で崩れないこと）
- 配色・フォントは既存サイトに準拠（深い藍色・墨色ベース＋金・朱の差し色、明朝体）

## 編集のしやすさ

未確定情報および教義に関わる表現には、既存サイトと同じ方式で日本語の編集用コメント（`<!-- ※〜を書き換えてください -->`）を入れる。対象は以下。

- 電話番号・メールアドレス（プレースホルダー）
- 法要に関する記述（教義に関わるため住職確認が必要）
- 写真（後日差し替え）

## スコープ外（今回は対応しない）

- 実際のホスティング作業・ドメイン取得（公開方法の決定は本スペック完了後の別作業）
- Googleビジネスプロフィールの登録作業そのもの（手順書の作成までを本スペックの範囲とする）
- 問い合わせフォームのバックエンド処理（電話・メールでの受付とする）
- 葬儀社向けページ（今回は作らない）
- お布施の金額掲載（永代供養墓の費用とは性質が異なるため掲載しない）

## 検証方法

- ブラウザで `eitaikuyo.html` と `index.html` を開き、PC 幅・スマホ幅の両方でレイアウト崩れがないことを確認する
- 2ページ間の相互リンク（トップ→永代供養墓、永代供養墓→トップ）が正しく機能することを確認する
- トップページ内の全アンカーリンクが引き続き正しく動作することを確認する
- 掲載した費用が確定情報と一致していることを確認する（檀家以外 15万円 / +3万円、檀家 10万円 / +2万円、基本料金に1体含む）
- 合祀のため取り出せない旨が明記されていることを確認する
- 追善供養を意味する表現（「回向」等）が含まれていないことを確認する
