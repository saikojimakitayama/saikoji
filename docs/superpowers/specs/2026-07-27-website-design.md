# 西光寺ホームページ 設計スペック

## 背景・目的
依頼者の実家が管理する寺院「西光寺」（浄土真宗高田派、三重県鈴鹿市）を紹介するホームページを作成する。現時点ではローカルで閲覧できれば良く、将来的に無料ホスティング（GitHub Pagesなど）にそのままアップロードできる形にしておく。

## 基本情報（確定事項）
- 寺名: 西光寺（さいこうじ）
- 宗派: 浄土真宗高田派
- 住職: 瀬古 和順
- 所在地: 〒513-0848 三重県鈴鹿市平田本町2丁目7-20
- 納骨堂: なし（お墓・供養の案内は掲載するが納骨堂の記載はしない）
- 由緒・詳細プロフィール・行事日程・連絡先: 未確定のため仮文章／プレースホルダーで作成し、後から差し替え可能にする
- 実写真: 鐘楼・本堂の外観写真1枚あり（`images/shourou-hero.png`）。他はプレースホルダー。

## 技術構成
- ビルド不要の静的サイト（HTML / CSS / JS のみ、フレームワーク・依存パッケージなし）
- ブラウザで `index.html` を直接開いて閲覧可能
- ディレクトリ構成:
  ```
  西光寺ホームページ/
    index.html
    css/style.css
    js/script.js
    images/
      shourou-hero.png（提供写真）
      その他プレースホルダー画像はCSSで代用
    docs/superpowers/specs/（本スペック）
  ```

## ページ構成（単一ページ + アンカーナビゲーション）
1. ヘッダー / ナビゲーション（スマホ用ハンバーガーメニュー付き）
2. ヒーローセクション: 提供写真を背景に寺名・キャッチコピー
3. 寺の紹介・由緒（仮文章、宗派・所在地は確定情報を反映）
4. 住職・寺族の紹介（瀬古 和順、プロフィールは仮文章）
5. 年間行事・法要案内（浄土真宗の一般的な年間行事を仮設定：修正会・春彼岸会・盂蘭盆会・秋彼岸会・報恩講など）
6. お墓・ご供養のご案内（仮文章）
7. アクセス（住所 + Googleマップ埋め込み）
8. お問い合わせ（電話・メールはプレースホルダー）
9. フッター（コピーライト等）

## ビジュアルデザイン
- テイスト: 和風・落ち着いた伝統的な雰囲気
- 配色: 深い藍色・墨色をベースに、金・朱を差し色として使用
- フォント: 明朝体ベース（見出しは大きめ、和の雰囲気を強調）
- ヒーロー背景に実写真を使用、他セクションはCSSグラデーション＋和柄パターンで控えめに装飾（後で画像に差し替え可能な構造にする）
- レスポンシブ対応（PC・スマホ両方で閲覧しやすいレイアウト）

## 編集のしやすさ
- 由緒・住職紹介・行事日程・連絡先など仮情報の箇所には、HTML内に日本語コメント（例: `<!-- ※ここを実際の由緒に書き換えてください -->`）を入れ、後から住職や家族が編集しやすいようにする
- 画像差し替えは `images/` フォルダ内のファイルを置き換えるだけで反映される構造にする

## スコープ外（今回は対応しない）
- サーバーサイド機能（フォーム送信のバックエンド処理、予約システムなど）
- 実際のホスティング・ドメイン取得作業
- 多言語対応
- CMS等の管理画面

## 検証方法
- ローカルでブラウザ表示を確認（PC幅・スマホ幅の両方でレイアウト崩れがないか）
- 主要リンク（アンカーナビ、Googleマップ埋め込み）が正しく機能するか確認
