# 問い合わせフォームの作り方（Googleフォーム）

ホームページに「問い合わせフォーム」を置くための手順です。
無料で、10分ほどでできます。

---

## なぜフォームが要るのか

永代供養墓や墓じまいを調べているのは、ご本人（60〜70代）よりも、
その子世代（40〜50代）であることが多いといわれています。

この世代は、いきなりお寺に電話をかけることに気おくれを感じがちです。
「まだ決めていないのに電話するのは申し訳ない」と思って、そのまま離れてしまう。

フォームがあれば、夜でも休日でも、気軽に一行だけ書いて送れます。
**電話をなくすのではなく、電話をためらう人の受け皿を増やす**のが目的です。

---

## ステップ1：Googleアカウントを用意する

すでにお持ちなら、それを使ってください。
まだなければ https://accounts.google.com/signup で作れます（無料）。

> **おすすめ**：Googleビジネスプロフィール（`google-business-profile-guide.md`）でも
> 同じアカウントを使います。お寺用のアカウントを1つ作って、
> 両方をそれで管理するのが分かりやすいです。

## ステップ2：フォームを作る

1. https://docs.google.com/forms/ を開く
2. 「空白のフォーム」を選ぶ
3. 一番上のタイトルを **西光寺 お問い合わせ** に変える
4. その下の説明欄に、次の文を貼り付ける

```
永代供養墓・墓じまい・法要などについてのご相談を承っております。
ご連絡先は、お電話・メールのどちらか一方で構いません。
折り返しご連絡いたします。
```

## ステップ3：質問を作る

右側の「＋」ボタンで質問を追加していきます。
次の6つを、この順番で作ってください。

| # | 質問 | 種類 | 必須 |
|---|---|---|---|
| 1 | お名前 | 記述式 | ● |
| 2 | ふりがな | 記述式 | |
| 3 | 電話番号 | 記述式 | |
| 4 | メールアドレス | 記述式 | |
| 5 | ご相談の内容 | ラジオボタン | ● |
| 6 | ご質問・ご要望 | 段落 | |

**5番の選択肢**は次の4つにします。

- 永代供養墓について
- 墓じまいについて
- 法要について
- その他

「必須」の欄に●が付いているものは、質問の右下にある
**「必須」のスイッチをオン**にしてください。

## ステップ4：回答がメールで届くようにする

作っただけでは、回答が来ても気づけません。**この設定を必ず行ってください。**

1. 上の「回答」タブを押す
2. 右上の縦三点（︙）を押す
3. **「新しい回答についてのメール通知を受け取る」** を選ぶ

これで、問い合わせが入るたびにメールが届きます。

## ステップ5：URLを控える

1. 右上の **送信** ボタンを押す
2. 鎖のマーク（🔗）のタブを選ぶ
3. 表示されたURLをコピーする

このURLを教えてください。ホームページに組み込みます。

---

## 作ったあとに気をつけること

**メールを見る習慣をつけてください。** フォームは24時間受け付けますが、
返信が来ないと「対応してもらえない寺」と受け取られます。
1〜2日以内にお返事できる体制にしておくのが安心です。

**迷惑メールに入っていないか、最初に確認してください。**
ご自身で一度テスト送信してみて、通知メールが届くか試すことをおすすめします。

---

## よくあるつまずき

| 症状 | 対処 |
|---|---|
| 通知メールが来ない | ステップ4の設定を忘れています。「回答」タブから設定してください |
| 通知は来るが内容が書いていない | メール本文の「回答を表示」を押すと内容が見られます |
| 質問を間違えて消した | 左下の「元に戻す」で戻せます |
| 誰でも回答できるか不安 | ログイン不要で誰でも送信できる状態が正しい設定です |
